# 纸上练 · 当前后端重构设计

更新：2026-11-05。**状态：两级目录与多规则模板后端已实现并完成真实浏览器联调。**目录名v1表示一期范围。实际数据库与接口见02、03，交付验证和后续边界见[联调记录](../../implementation/两级目录与多规则后端联调.md)。

## 已确认的产品规则

- 目录只分两级：一级目录组织内容，二级叶子目录关联多个代码出题组件。取消独立知识点、达成目标和目录分类字典。
- 模板属于一个一级目录，包含多条规则。每条规则指定二级目录、组件、题型、难度、题数；支持多个二级目录及混合难度。总题数为规则题数相加。
- 不再设置独立年级/学期字段。模板使用易懂名称和自由标签，标签可以是专项、真题等文字；没有强制年级维度。
- 用户默认进入生成历史，点击生成练习，直接按名称和标签选择模板，确认后提交。未发布或不可用模板不展示，不要求用户选择目录。
- 管理员审核题目教学合理性；系统仍必须保证实际生成能力、数量、数学答案和文件完整性，不能通过配置创造算法。
- 管理端样例按模板完整题数、每行1～5题和A4分页生成；学生版与解析版来自同一批题。
- 匿名Cookie、单管理员、SQLite、API+worker队列、后端保存PDF保留。只有题目校验、两份PDF及成功事务全部完成后才开始600秒冷却。
- 时间统一Asia/Shanghai，界面不重复标注时区，试卷不展示生成时间。
- 用户允许重新设计甚至重建数据库。当前采用独立新库，旧运行库和PDF保留。

## 当前实施选择

- 单规则1～100题、整卷最多200题、最多30条规则；每行1～5题。
- 编辑已发布模板产生新草稿，旧版持续开放，审核后切换发布指针。
- 目录/组件/关联失效立即阻止相关模板的新生成；不删除历史。
- 新库papr-v2.sqlite3、新文件根generated-v2；旧管理员账号复制，内容配置可从浏览器导入为草稿。
- v2业务接口与v1身份/设置接口共存；目录及规则采用JSON配置快照，具体与早期建议的差异已在02、03中说明。
- 01/04/05/07中的运行扩展建议不等于全部实现；当前边界以联调记录为准。

## 2026-11-10 模板配置调整

模板规则的二级目录选项仅展示已关联组件的目录；原规则如已失去关联，会显示不可选的提醒项，需重新选择。

模板新增`columns_by_kind`：竖式计算、选择题、填空题、解答题分别设置每行1～5题，学生版与解析版使用相同的题型列数。新模板默认竖式2题/行，其余1题/行；旧版本未配置该字段时沿用原columns，历史PDF不重排。修改列数属于版本内容变更，须重新样例、验证、审题发布。发布结果在发布按钮下方即时显示。

## 2026-11-11 四年级上册组件

新增11个参数化组件，按用户已有11个二级目录追加关联；组件能力清单从管理端workspace接口的components读取，不在前端维护另一份能力声明。Rule.kind和columns_by_kind新增“判断题”“应用题”；打印联合类型增加curriculum，支持结构化SVG图示。生成指纹包含新增组件源文件，修改算法后必须重新验证审题。
