# v2接口与数据契约

更新：2026-11-05。以下路由已注册；完整输入结构及实际路径以[生成的OpenAPI](../../contracts/openapi.json)为准，由`scripts/export_contracts.py`导出。

成功响应为`{data,request_id}`，错误沿用统一错误封装。所有管理接口鉴权；写接口验证Origin与CSRF，修改配置带revision。分页使用offset/limit。用户与管理端使用独立HttpOnly Cookie；身份初始化、管理员登录与CSRF仍复用v1接口，分别签发v2路径的独立命名Cookie。

## 管理接口

以下相对`/admin/api/v2`。

| 方法与路径 | 用途 |
| --- | --- |
| GET /workspace | 目录树、模板、组件状态、最新预览/验证/审题证据 |
| PUT /items/{kind}/{id} | kind为catalogs、nodes、templates，适配当前页面字段；新建UUID，revision=0；已有记录必须匹配revision |
| PATCH /components/{key} | 启停已安装组件 |
| POST /workspace/import | 空内容库一次性导入浏览器旧配置；映射旧ID，模板仅保存草稿，事务失败全部回滚 |
| POST /versions/{id}/jobs/{action} | action为preview或validate；带version_id、configuration_hash及Idempotency-Key |
| GET /jobs/{id} | 任务进度、完整样卷结果与资产 |
| GET /artifacts/{id} | 鉴权访问实际PDF |
| POST /versions/{id}/review | preview_id、validation_id、approved、comment |
| POST /templates/{id}/publish | revision、version_id、review_id；也用于回退到有效已审版本 |
| POST /templates/{id}/disable | revision，关闭新生成 |
| GET /templates/{id}/versions | 历史版本及审题证据 |
| GET /operations | 用户生成记录 |
| GET /statistics、GET /overview | 基础统计；overview支持date_from/date_to |
| POST /papers/{id}/notices | 勘误message、withdraw，撤回后用户无法下载 |
| GET /audit | 内容操作审计 |

版本规则字段：node（二级目录ID）、generator（代码组件key）、kind、difficulty、count。模板带catalog（一级目录ID）、name、code、tags、description、columns、rules。请求限制单规则1～100题、最多30条、整卷最多200题、每行1～5题；未知字段拒绝。前端不能用status直接绕过审题发布。

## 用户接口

以下相对`/api/v2`。

| 方法与路径 | 用途 |
| --- | --- |
| GET /templates | 仅可用发布模板，名称、标签及规则摘要 |
| POST /jobs | version_id、configuration_hash，Idempotency-Key；服务端重新检查当前发布与依赖 |
| GET /history | 本主体历史，offset/limit |
| GET /jobs/{id} | 本主体任务进度与文件 |
| POST /jobs/{id}/cancel | 仅取消queued任务 |
| GET /files/{id} | 本主体ready文件；校验大小/hash，撤回后拒绝访问 |

同key同请求返回原任务，不重复生成；不同请求同key冲突。失败后新key重试。只在完整成功后开始600秒冷却；历史查看与下载不延长冷却。

## 快照和兼容

当前共享打印输入仍使用schema_version=1，扩展为乘法/大数读写联合类型，增加规则索引和数学签名，不采用此前建议但未实施的schema_version=2。学生版与解析版源自同一快照。身份、设置等仍用v1，旧内容路由保留但当前新流程不调用。

## 2026-11-10 模板配置调整

模板规则的二级目录选项仅展示已关联组件的目录；原规则如已失去关联，会显示不可选的提醒项，需重新选择。

模板新增`columns_by_kind`：竖式计算、选择题、填空题、解答题分别设置每行1～5题，学生版与解析版使用相同的题型列数。新模板默认竖式2题/行，其余1题/行；旧版本未配置该字段时沿用原columns，历史PDF不重排。修改列数属于版本内容变更，须重新样例、验证、审题发布。发布结果在发布按钮下方即时显示。

## 2026-11-11 四年级上册组件

新增11个参数化组件，按用户已有11个二级目录追加关联；组件能力清单从管理端workspace接口的components读取，不在前端维护另一份能力声明。Rule.kind和columns_by_kind新增“判断题”“应用题”；打印联合类型增加curriculum，支持结构化SVG图示。生成指纹包含新增组件源文件，修改算法后必须重新验证审题。

当前运行库恢复为包含用户录入内容的papr.sqlite3，原空内容库保留。具体数学范围、教材对应边界、关联备份及验证结果见[四年级上册出题组件](../../implementation/四年级上册出题组件.md)。
