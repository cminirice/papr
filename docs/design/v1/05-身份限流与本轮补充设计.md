# 身份、安全与运行设计

更新：2026-11-05。核心流程已实施，具体数据结构与接口以02、03为准；本文的扩展建议未全部实现，实际边界见[联调记录](../../implementation/两级目录与多规则后端联调.md)。

## 身份

用户无需注册。持久HttpOnly Cookie关联服务端匿名主体；建议会话90天、剩余不足7天续期，生产HTTPS使用Secure、SameSite=Lax。Cookie不存个人资料；数据库只存随机令牌hash。清Cookie、无痕会话结束或换设备可能失去历史入口，IP不能用于合并或找回。

后台单管理员，密码哈希，独立Cookie/CSRF域；用户身份不能访问管理资源。写请求校验Origin与CSRF；登录失败限流，口令、令牌、Cookie不进入日志。下载和预览均走鉴权接口，非本人资源404。

## 准入与资源

每主体最多一个queued/running用户生成任务。只有完整成功开始600秒冷却；失败/取消不新增冷却。IP仅辅助限流，全局队列有界。建议初始worker执行槽1、队列长度20、每条规则最多100题、整卷200题、规则30条；这些为待压测默认值，不是用户已确认限制。

任务种类共用有界队列，建议管理员验证与用户出卷轮换调度避免饥饿。数学子进程、浏览器超时和内存预算独立配置。worker实际渲染/解析探针通过且指纹与部署一致才报告ready；未就绪不接新用户出卷。

## 统计与日志

报表按Asia/Shanghai自然日，显示受理数、成功数、失败数、处理中数、耗时分位数、当前可用模板数与PDF请求数。受理按created_at、成功按finished_at分别统计并标明口径。重放幂等请求不重复计生成；重试attempt与任务数分开。打印按钮点击或HTTP返回不等于用户实际打印。

管理员审计记录目录编辑、组件关联/停用、草稿编辑、审核、发布、停用、回退、修复与勘误；摘要限制字段，不序列化整份请求凭证。日志关联request_id/job_id但不泄露会话。

## 备份与保留

数据库与ready文件作为一致恢复单元；使用SQLite在线备份或停写备份，核对ready索引、文件hash与清单，定期演练恢复。配置、代码/组件/字体/渲染版本也记录在备份清单；密钥另行安全存储，不进仓库。

开发阶段不自动删除成功历史或PDF。正式试用前确定历史、PDF、管理员样例、审计和日志的保留周期及磁盘告警阈值。失败attempt临时文件只在租约失效、任务终止、确认无引用后清理，与正式历史保留策略分开。

现有服务启动方式见[操作手册](../../manual/服务编译启动与停止手册.md)。本文不代表已经完成部署或资源容量验证。
