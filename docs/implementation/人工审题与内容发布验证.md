# 人工审题与内容发布验证

日期：2026-10-27，北京时间。本批单终端顺序承担T0迁移与契约、T2审题/发布、T5共享乘法渲染器和T6操作界面。未启动子代理。

## 已完成的最小流程

1. 在后台完成当前草稿的批量验证，打开通过报告的“查看样题与发布”。
2. 逐题检查报告保存的样题；切换学生版/解析版，并用辅助浏览器打印检查实际排版和答题留白。
3. 勾选已经检查的样题、填写意见，明确选择通过或不通过。表单初始为“不通过”，打印检查默认未勾选。批准必须引用该报告全部样题并显式确认打印检查；任何自动检查都不会代填人工批准。
4. 检查列出的知识点定义/边界和目标达成标准，填写理由，分别发布知识点修订、目标修订。目标要求同知识点修订先发布；此操作不宣称教材版本已核验，也不自动激活目录。
5. 明确点击发布模板版本。发布事务核验同版本/hash通过报告、最新人工批准、算法/参数schema/配置/有效题量、已发布依赖，随后原子切换指针、冻结版本、递增epoch并追加发布/审计记录。

未执行以上真实审题操作；所有自动测试中的批准都明确为测试模拟。浏览器样张打印仅用于后台审题辅助，不替代一期“后端生成并保存两版PDF”的要求。当前尚无后端PDF产物，未验收真实纸面效果。

## 接口与事务

- 0005新增content_review、content_release、admin_operation_log。review额外存print_checked，表示管理员明确提交的检查确认，不是系统验证了物理打印成功。
- GET `/template-versions/{id}/release-context`返回只读前置修订、模板锁版本、当前指针及最近50条审题记录。
- POST `/template-versions/{id}/reviews`要求版本If-Match，绑定validation_run_id/content_hash/sample_refs，追加approved/rejected记录。样题引用来自报告快照，不能引用任意UUID；通过要求全部样题，驳回可引用其中至少一道。
- POST `/knowledge-revisions/{id}/publish`、`/objective-revisions/{id}/publish`要求各自If-Match及content_hash/reason。将修订发布、更新主体当前指针并启用、递增主体/修订锁与epoch、追加审计；不覆盖已发布修订。
- POST `/templates/{id}/publish`、`/disable`、`/enable`、`/rollback`要求模板If-Match和非空理由。发布/启用/回退还要求version_id/validation_run_id/review_id。所有写接口均有独立管理员会话、Origin/CSRF，并在事务内重验身份。
- publish只接受本模板草稿；enable只能恢复停用模板原指针；rollback只能指向同模板不同的已发布、未退役且验证/审题仍有效的版本。disable保留历史指针；历史内容不被重写。
- 同一hash有多次审题时，仅最新一条允许参与发布；最新驳回会阻止旧批准。相同reviewed_at按SQLite插入顺序区分，避免固定时钟或极近时间的记录顺序不确定。
- 发布、指针、release、epoch及审计在同一BEGIN IMMEDIATE中；并发同锁发布只有一个成功。任何审计写入错误会回滚整个操作。
- POST `/templates/{id}/versions`从本模板已发布版本复制新草稿，版本号在同一事务分配；已有草稿时拒绝再复制。仅复制内容/目标/用例，清空有效题量，不复制run/review；旧版本保持不可编辑。新草稿需重新验证、审题后发布。

审题与发布操作当前无独立幂等key。If-Match防止重复发布、启停、复制；响应丢失后须刷新核对，不能盲目重试。人工审题不递增内容锁，同一草稿允许追加更正结论。请求ID写入审计，审计不保存Cookie或凭证。

回退0005会删除审题/发布/审计表。为避免丢失审核证据后内容仍启用，迁移先停用已有发布指针的启用模板并递增epoch，保留版本和指针；重新升级不自动恢复审核证据或启用。仅在临时测试库执行过回退。

## 渲染边界

`frontend-shared/src/QuestionRenderer.vue`为共享的首个乘法渲染器。学生版仅呈现题目/竖式因数与按毫米留白，解析版显示两个实际部分积、结果和三步解释；十位部分积已经乘10，不重复左移。内容使用Vue文本插值，不插入任意HTML。后台打印样张按A4/15mm页边距设置，暂未实测中文字体、跨页和实际打印尺寸。

共享组件只支持已实现的乘法契约，不宣称几何/表格/其他题型已可渲染。后续后端PDF复用此组件，但还需受控打印页面、字体、渲染就绪信号及PDF文件检查。
