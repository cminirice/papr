## 数学与排版边界

- 组件共51种“组件×题型”组合、153种含难度的配置组合。每个组件有3种参数化问题结构，不是153套独立算法。
- 认识更大的数新增数位、比较、近似数；读数写数继续复用原先已关联的大数读写组件。整数乘法保留原有竖式及含零组件，并新增巧算与装箱情境。
- “我们生活的空间（二）”“数图形的学问”“图形的奥秘”尚未取得具体教材小节，当前按位置方向、图形计数、拼摆与周长面积实现上述范围；不宣称覆盖某教材全部小节。线与角组件本批重点为角分类和平角/周角计算，尚不包含量角器操作或任意作图题。
- 参数来自有限候选集合，先按实际题干和答案去重后计算容量。不同题型不重复使用同一题干；多规则按保守剩余容量判断，不保证任何组合均支持单规则100题。图形计数组件每档当前有130个不同候选题。
- 根据题型分别排版；判断题和应用题有独立大题标题，默认1题/行。图示包含角、方格、路线、拼摆、线段/三角形连线、尺寸图、条形图。大量点或拼摆只绘前若干项时明确标注省略。
- 样卷解答版沿用原有形式：先包含学生题目，再另起页附答案与解析。

## 数据与使用

已追加关联11/11目录，不覆盖原有关联，不改目录名称/编码/启用状态，不自动创建或发布模板。原来处于草稿的目录仍是草稿，使用前先在目录管理启用。

1. 刷新并登录管理台，在“出题组件”查看新增组件的能力详情。
2. 在“目录管理”检查对应关联；按需要启用一级/二级目录。
3. 模板添加规则，选择二级目录、新组件、题型、难度及题数。
4. 设置各题型每行题数，生成完整样卷、自动验证、人工审题，再发布。新算法上线导致旧验证指纹过期时同样需重新验证审题。
