# 本机试用

一期功能已进入本机试用。人工审题、实物打印及正式对外开放准备仍须分别完成，不能以自动测试代替人工确认。

后台页面功能、操作顺序及完整发布案例见[后台管理功能与使用手册](../manual/后台管理功能与使用手册.md)。该手册也记录了2026-10-30核对的内容开放状态。

## 访问与配置

- 用户端：http://127.0.0.1:5173
- 管理端：http://127.0.0.1:5174
- API：http://127.0.0.1:8001/api/v1/health
- API使用8001：8000已由本机AgentGate占用，未停止或修改该服务。
- 当前配置在根目录`.env`，不纳入仓库；数据库`backend/var/papr.sqlite3`，PDF根目录`backend/var/generated`。
- 本机管理员用户名`admin`，随机口令保存在`backend/var/local-admin.json`，文件权限600，不在对话、日志或命令参数中展示。不覆盖已有管理员。
- 用户端和管理端统一使用127.0.0.1，避免Cookie主机混用。

## 首次内容开放

初始化时准备了7个草稿：三位数乘两位数竖式、乘积填空、乘积选择、缺数填空、错误原因选择、纠错解答、含零因数竖式。当时数学验证均通过，未自动审题或发布；后续人工操作后的当前状态以管理台为准。O002与O003已映射到同一候选乘法主题，不宣称与具体教材版本同步。

1. 登录后台，在模板列表查看配置、验证报告与样题。
2. 检查题意、答案、解析、难度与固定用例；`backend/var/trial-review/`提供每个草稿的学生版和解析版PDF，`manifest.json`记录验证报告编号和内容hash。此为待审样张，不是用户生成历史；还需实际打印确认。
3. 在审题入口确认所检查的样题，填写真实审题意见和打印确认；若需调整，修改草稿并重新验证和审题。
4. 按依赖顺序发布知识点修订、训练目标修订，再发布模板。可以先开放一个模板，不必等全部审完。
5. 启用相应候选目录及主题，按实际验证支持范围设置知识点各难度/题型的题量档位。
6. 用户端刷新后选择开放内容，生成双版PDF。只有完整成功才开始600秒冷却；失败/取消不新增冷却。

未发布内容时，用户端没有可生成题量属于预期行为，不是PDF或服务故障。系统设置可以收紧题量和任务限额，不会绕过内容验证或人工审题。

## 重启

各服务的独立构建、启动、停止、端口检查及故障处理见[服务编译启动与停止手册](../manual/服务编译启动与停止手册.md)。

每个终端先进入工程目录并载入本地配置：

```bash
cd /Users/eric/PycharmProjects/papr
set -a
. ./.env
set +a
export PATH=/Users/eric/.local/node-v22.23.2/bin:$PATH
```

分别启动以下四个进程（只运行一个worker）：

```bash
backend/.venv/bin/uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8001 --no-proxy-headers
backend/.venv/bin/python scripts/worker.py
npm run dev:web
npm run dev:admin
```

worker出现“PDF真实探针通过，用户worker就绪”且心跳有效才开放新的生成请求。构建打印资源或更换Chrome、字体后重启worker。API健康接口仅说明进程存活，不代替PDF就绪检查。

## 保留、资源与备份

本机试用保持自动清理关闭，不删除历史或样张。默认全局处理中上限10，同IP每600秒受理上限12，成功冷却固定600秒。当前磁盘可用约272GiB；这些参数通过功能边界测试，不代表正式生产吞吐保证。

临时数据库和ready文件的备份恢复测试已通过。实际运行库备份须使用SQLite在线backup接口或停服务后的完整一致副本，并一同保存PDF根目录及限流密钥；不得只复制正在写入的SQLite主文件。正式对外开放前另行落实保留周期、定期备份、容量、HTTPS和进程托管。
