# 模板草稿编辑验证

日期：2026-10-27，北京时间。本批实现首个乘法模板的受控编辑，单终端串行承担T0契约、T2服务和T6页面；不新增迁移，head仍为0003。

## 已实现接口与页面

- GET `/admin/api/v1/templates/{id}`：模板及版本列表。
- GET `/admin/api/v1/template-versions/{id}`：草稿配置、固定用例、生成器/目标标识、更新时间、content_hash、lock_version及editable；ETag格式为`"1"`。
- PATCH同一版本路径：必须携带管理员Cookie、Origin、JSON Content-Type、X-CSRF-Token和If-Match。If-Match只接受带双引号的正整数；缺失或格式错误422，过期409 EDIT_CONFLICT。
- PATCH仅接受`profiles`与`test_cases`。当前保留已有难度档位，允许修改数值范围、零/进位约束、单卷上限、留白及固定用例。每档至少一个用例，总计最多30个，同档编码唯一；不支持挑战或任意脚本。
- 不开放修改算法、目标、题型、题干/解析规则、身份字段、发布状态、发布指针或有效验证结果。仅支持首个O002修订1/目标修订1的乘法组件及显式fixed用例；不把未来扩展配置默默转换成现有格式。
- 管理端“查看配置”进入表单，可选版本、保存及显式重新加载。保存冲突或服务异常保留当前输入，不自动重放冲突写请求；CSRF轮换仅自动恢复一次。重新加载会放弃尚未保存修改。

## 一致性与hash

固定用例的数学计算在写事务外执行：按实际profile构造并独立校验题目，检查输入的预期答案。这里只检查至多30个固定用例，不运行随机批量验证或穷举容量；保存成功不代表该题量已验证可用。

最终BEGIN IMMEDIATE事务重验管理员会话和CSRF、草稿lock_version、未发布状态、生成器部署指纹及schema、关联配置。已发布/退役版本禁止原地修改。profiles与固定用例一起更新；所有profile有效题量清空、profile_hash重算，版本content_hash重算且lock_version加1。模板更新时间同步，时间仍按北京时间；草稿保存不递增公开内容epoch、不设置冷却。

编辑后的content_hash绑定：不可编辑题干/答案/解析配置、输出schema版本、算法/校验版本及指纹、目标与知识修订hash，以及规范排序的profiles/固定用例和去重规则。时间、锁版本、派生有效题量不参与hash。列表排序变化不改变hash。

初次种子hash记录完整导入输入；首次编辑保存转为运行库聚合hash，即使配置值没有变化，也会使种子离线报告不再对应当前hash。后续正式验证任务必须从运行库草稿取快照并绑定当前hash，不能用工程内离线报告冒充正式validation_run。本批尚无validation_run/review表，未来接入时需将旧run标stale，并禁止复用不同hash的审题记录。
