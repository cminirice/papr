# 身份链路验证

日期：2026-10-27（北京时间）。本批是T0共享基础与T1身份服务，顺序接入两个前端；不是完整生成链路验收。没有创建Git分支/提交、推送或部署，没有设置真实管理员口令。

## 实现范围

- 唯一迁移head：0002，新增app_user、user_session、admin_user、admin_session、rate_limit_event、job；外键、北京时间、单管理员、用户活跃任务及幂等唯一约束落到SQLite。
- 持久匿名会话、续期、独立管理员会话、Origin/JSON/CSRF、登录限流、IP HMAC与不覆盖式初始化命令。
- 管理员密码采用Argon2id，校验不占SQLite写锁；停用管理员时可统一撤销其会话。
- 身份准入与成功冷却接口供T4在自身短事务中调用。当前没有任务受理路由、worker、paper/file_asset发布或PDF生成。
- 后端生成共享TS/JSON Schema/OpenAPI；包括真实的统一错误响应。用户页匿名bootstrap后验证Cookie可用；管理页登录、刷新恢复、CSRF一次重试和退出。
