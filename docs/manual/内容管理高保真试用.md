# 内容管理操作流程

更新：2026-11-05。当前页面已连接真实后端，数据存入SQLite，样例及用户练习由worker生成PDF。

## 从零发布案例

目标：发布“乘法与大数读写练习”，含6道乘法题和3道大数读写题。

1. 登录管理台，进入“内容管理 → 目录管理”。新建一级目录“数学专项”，编码`MATH_PRACTICE`，保存并启用。
2. 在该目录下添加二级目录“乘法练习”，编码`MULTIPLICATION`，保存并启用。点击“关联组件”，勾选整数乘法组件并保存。
3. 添加二级目录“大数读写”，编码`NUMBER_READING`，启用后关联大数读写组件。出题组件管理中对应组件也须启用。
4. 在“模板管理”新建模板，填写名称“乘法与大数读写练习”、编码`MIXED_PRACTICE`及标签“专项”。选择一级目录“数学专项”。
5. 添加第一条规则：乘法练习 → 整数乘法组件 → 竖式计算 → 基础 → 6题；第二条规则：大数读写 → 大数读写组件 → 填空题 → 基础 → 3题。每行设为2题，保存。
6. 进入“组卷预览”，点击“生成样例题查看”，等待完成。页面嵌入实际9题学生版PDF；切换“显示答案与解析”检查解析版。可打开PDF检查A4分页与留白。
7. 点击“运行自动验证”，等待成功。若失败，检查目录/组件状态、容量或worker错误，修改配置后重新生成样例并验证。
8. 检查题目、答案、难度和排版，填写审题意见，点击“审题通过”，再点击“发布模板”。自动验证不代替这一步人工审查。
9. 打开用户端，点击“生成练习”，按名称或标签选择刚发布模板，确认9题配置，生成后下载学生版与解析版。

## 编辑、停用与回退

列表提供编辑、组件关联、组卷预览等操作。已发布模板编辑后形成新草稿，旧版继续开放；新配置需重新样例、验证、审题、发布。组卷预览的“查看版本历史”可回退到证据仍有效的旧版本。

目录、组件或模板停用会阻止相关模板新出卷；已有历史保持。生成记录可查看详情、PDF，并添加勘误或撤回试卷；撤回会关闭用户下载，不删除记录。打印资源/组件代码更新后原验证指纹可能失效，需要重新验证审题。

## 原浏览器配置

空的新内容库支持在目录管理点击“导入此浏览器已有配置”。导入目录与规则并重建ID引用；模板全部为草稿，不把原本地启用状态当作已审核发布。服务器已有内容时拒绝整批导入，避免覆盖；浏览器原数据保留。旧数据库匿名历史不自动迁入新库。

当前部署了原有3个组件及新增11个四年级上册组件，范围见[组件交付清单](../implementation/四年级上册出题组件.md)。关联组件不会创造算法；新增算法仍需代码开发和验证。

## 2026-11-10 模板配置调整

模板规则的二级目录选项仅展示已关联组件的目录；原规则如已失去关联，会显示不可选的提醒项，需重新选择。

模板新增`columns_by_kind`：竖式计算、选择题、填空题、解答题分别设置每行1～5题，学生版与解析版使用相同的题型列数。新模板默认竖式2题/行，其余1题/行；旧版本未配置该字段时沿用原columns，历史PDF不重排。修改列数属于版本内容变更，须重新样例、验证、审题发布。发布结果在发布按钮下方即时显示。
