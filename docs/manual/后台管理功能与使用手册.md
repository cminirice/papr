# 后台管理功能与使用手册

更新：2026-11-05。管理台 http://127.0.0.1:5174 ，用户端 http://127.0.0.1:5173 。

| 功能 | 操作与作用 |
| --- | --- |
| 数据概览 | 查询新工作流提交、成功、失败及队列数据 |
| 目录管理 | 维护两级目录树，叶子目录关联代码组件 |
| 出题组件 | 查看已部署能力并启停，不能在线编写任意算法 |
| 模板管理 | 多条目录/组件/题型/难度/数量规则，自由标签，每行1～5题 |
| 组卷预览 | 生成实际完整学生/解析PDF、自动验证、人工审题、发布和版本回退 |
| 生成记录 | 查看任务结果和PDF，添加勘误或撤回用户下载 |
| 操作审计 | 查询新内容工作流操作 |
| 系统设置 | 队列/IP限额及保留状态，成功冷却固定600秒 |

完整从零发布案例见[内容管理操作流程](内容管理高保真试用.md)。模板列表保存只创建草稿；发布前必须完成完整样例、自动验证与人工审题。用户端看不到模板时依次检查一级/二级目录启用、组件启用和关联、模板是否实际发布、验证是否与当前内容和运行资源匹配。

管理员账号沿用旧库账号，首次切换后重新登录。浏览器旧配置可导入空的新库，模板仍需审核发布。启动四个服务的方法见[服务操作手册](服务编译启动与停止手册.md)。
