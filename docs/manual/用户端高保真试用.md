# 用户端操作流程

更新：2026-11-05。当前连接真实服务，用户无需注册，浏览器Cookie关联服务器历史。

1. 打开用户端进入练习历史，点击“生成练习”。
2. 按模板名称或自由标签搜索，选择模板；不需要先选年级、目录或知识点。
3. 核对各项题型、难度、题数和总数，点击“确认生成”。
4. 回到历史等待排队、生成和PDF保存完成。成功后打开学生版或解析版PDF下载、打印。
5. 排队中可取消；失败不会开始新冷却。完整成功后600秒才能再生成，已有文件随时查看，不延长冷却。
6. 刷新页面或正常重开同一浏览器仍可查看历史；清Cookie、无痕或换设备可能失去原历史入口。

未发布、已停用、依赖失效或验证指纹过期的模板不会展示。后台勘误会出现在历史详情，撤回的试卷不再开放下载。当前列表显示最近100条记录。

旧高保真本地历史不是实际PDF历史，不导入为成功记录。新服务使用独立数据库，旧运行库及PDF仍保留。服务操作见[启动手册](服务编译启动与停止手册.md)。
